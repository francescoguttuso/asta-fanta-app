# Server Dashboard v9

Modifiche richieste rispetto alla v8, limitate alla visualizzazione Server mobile:

- Nella schermata **Rose** torna visibile il **prezzo di acquisto (FM)** accanto a ogni giocatore.
- Nella navigazione mobile del Server sono nuovamente visibili tutte le sezioni, incluse **Fanta Schedina** e **Highlander**.
- Il layout Rose mobile resta a **una squadra per volta** e il cestino resta sempre visibile.
- Nessuna modifica alla logica asta, ai dati Firestore, al Mobile Client, a Fanta Schedina o Highlander.
