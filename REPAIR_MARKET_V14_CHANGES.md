# Asta Riparazione

- Lo switch Server apre/chiude una sessione di asta riparazione.
- All'apertura viene salvato l'elenco degli ID presenti nelle rose.
- Durante la sessione, solo quei giocatori possono essere sostituiti e usati come copertura del budget.
- I giocatori acquistati durante la sessione non possono essere sostituiti nella stessa sessione.
- Alla chiusura la fotografia viene rimossa; la successiva apertura crea una nuova fotografia.
- Asta normale, Fanta Schedina, Highlander e UI Mobile non vengono modificati graficamente.
