# FantaRiggio Server v5

Questa prova parte dal Mobile Client v13 approvato e ne mantiene invariati i componenti mobile principali.

## Dashboard Server
- Sidebar desktop dedicata.
- Banditore con maglia, giocatore e countdown circolare stile Mobile Client.
- Selettore "Rilancio Server per": +1/+5/+10 registrano l'offerta a nome della squadra selezionata.
- Partecipanti asta, ultimo offerente, storico offerte e crediti.
- Elenco giocatori con ricerca, filtri, lettere e CHIAMA.
- Correzione / assegnazione manuale.
- Ultimo acquisto.
- STOP disponibili per la squadra selezionata.
- Import/export squadre e azioni CSV/Excel, JSON e reset mantenute.

I file MobileController, MobileAuctionPanel, FantaSchedinaMobile e HighlanderMobile sono gli stessi della v13 approvata.
