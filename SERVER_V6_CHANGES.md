
## V6 – Offerta Server come squadra
- Il pannello Server ora espone chiaramente `OFFERTA COME`.
- La squadra selezionata dal Server è quella a cui vengono attribuiti i rilanci `+1 / +5 / +10`.
- I rilanci continuano a passare dal controller offerte esistente (`faiOfferta` / `placeBid`): non viene introdotta una seconda logica d'asta.
- Il pannello crediti è presentato come `CREDITI RESIDUI`.
- Nessuna modifica runtime a FantaSchedina o Highlander.
